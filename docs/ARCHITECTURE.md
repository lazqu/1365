## 📌 1. 아키텍처 구성

본 프로젝트는 정적 데이터를 기반으로 웹 브라우저에서 직접 정렬 및 검색을 수행하도록 구성하고 있습니다:

1. **CI/CD 파이프라인 기반 자동 수집 및 배포 (`update_data.py`)**:
   - GitHub Actions CI/CD를 통해 1365 공공 API 데이터를 주기적으로 자동 수집 및 정적 데이터 파일(`data.json`, `data.js`) 갱신·배포
2. **클라이언트 측 탐색 및 정렬 (`index.html`, `area_mapper.js`)**:
   - 수집된 정적 데이터를 브라우저로 로드하여, 추가 통신 없이 다중 정렬 및 검색 처리

---

## ⚡ 2. 주요 처리 방식

- **정적 데이터 활용**: 매번 API를 직접 호출하지 않고 저장소에 수집된 정적 데이터(`data.json`)를 활용
- **클라이언트 측 정렬**: 사용자가 설정한 우선순위에 따라 브라우저에서 공고 데이터를 재정렬하여 표시
