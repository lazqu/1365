# 1365 자원봉사 스마트 탐색기 (1365 Volunteer Smart Explorer)

> ⚡ **1365 자원봉사 포털 공고를 더 쉽고 편하게 탐색하는 서드파티(Third-Party) 웹 탐색기**

행정안전부 1365 자원봉사 포털 공공데이터를 활용하여, **원하는 기준의 다중 정렬과 더 정밀한 검색 옵션을 제공하기 위해 개발하고 있는 웹 탐색기**입니다.

---

## 📌 개발 배경 (Why Smart Explorer?)

1365 자원봉사 포털을 이용하면서 개인적으로 더 필요하다고 느낀 기능들을 직접 구현하고자 개발을 진행하고 있습니다:

- **원하는 기준의 공고 정렬**: 모집마감일, 봉사시작일, 공고제목 등 원하는 순서대로 공고 정렬
- **더 정밀한 검색 옵션**: 키워드 포함/제외 필터링, 특정 공고 관심 등록 및 숨기기 등 세부 조건 설정

*(※ 현재 다중 정렬 기능을 제외한 대부분의 기능은 수정 및 추가 개선 작업이 필요한 상태입니다.)*

---

## 🌐 웹 서비스 접속 (Quick Start)

본 프로젝트는 **GitHub Pages**로 배포되어 별도의 프로그램 설치 없이 웹 브라우저에서 바로 사용할 수 있습니다.

- 🔗 **웹 탐색기 바로가기**: [1365 자원봉사 스마트 탐색기 접속](https://lazqu.github.io/1365/)
- 🔄 **자동 데이터 갱신**: GitHub Actions를 통해 **매일 2회(한국 시간 06시, 13시)** 1365 공공 API의 최신 봉사 데이터가 `data.json`에 자동으로 반영됩니다.
- 💻 **로컬 실행**: 저장소를 클론한 뒤 `index.html` 파일을 직접 열어 실행할 수도 있습니다.

## ✨ 주요 사용자 기능 (Key Features)

### 🔀 1. 사용자 지정 다중 정렬
* **우선순위 배치**: 모집마감일, 봉사시작일, 공고제목 등 여러 정렬 기준의 우선순위를 드래그 앤 드롭(`⠿`) 및 화살표(`▲▼`)로 재배치할 수 있습니다.
* **원클릭 ON/OFF 스위치**: 정렬 기능을 끄더라도 설정한 정렬 블록 상태는 유지되며 원천 순서로 바로 전환할 수 있습니다.
* **독립적 정렬 방향**: 각 조건별로 오름차순(⬆️) / 내림차순(⬇️)을 설정하여 재정렬합니다.

### 🔍 2. 포함 / 제외 키워드 설정
* **키워드 조건 검색**: 특정 키워드의 포함 여부 및 제외 여부를 지정하여 공고를 선별합니다.

### 🔥 3. D-DAY 마감 배지 & 요일 표기
* **마감 상태 표시**: `🔥 D-DAY`, `⚠️ D-3`, `⏳ D-7`, `🚫 마감됨` 배지로 마감 상태를 표기합니다.
* **날짜 및 시간 표기**: 날짜 항목에 한국어 요일(`화`, `수` 등) 및 일일 활동시간을 함께 표기합니다.

### ⭐ 4. 관심 공고 및 숨김 공고 관리
* **관심 공고 모아보기**: 관심 있는 봉사 공고는 `★ 관심` 버튼을 지정하여 별도로 모아볼 수 있습니다.
* **불필요 공고 숨기기**: 원치 않는 공고는 `🚫 숨기기` 버튼으로 제외할 수 있으며, 이 설정은 브라우저(`localStorage`)에 저장됩니다.
